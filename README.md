# 국내 증시·매크로 대시보드

[공개 사이트](https://asss4508.github.io/market-dashboard/) · [공통 데이터 계약](DATA_CONTRACT.md)

실제 공표 자료로 국내 시장, 자금, 매크로와 ETF 구성 변화를 비교합니다. 기존 8개 차트는 **전체 차트** 메뉴에 유지합니다. 전체 개요·투자자 수급·유동성·시장확산도·밸류에이션·선물옵션·매크로·백테스트·ETF 변화 메뉴를 제공합니다.

## 수집과 운영

- GitHub Actions는 한국시간 매일 07:41·16:17·19:23, 평일 09:13에 수집을 요청합니다. GitHub 예약 작업에는 실행 지연이 있을 수 있습니다.
- 정상 자료를 검증한 뒤 저장하고 사이트를 배포합니다. 일부 출처 실패 시 이전 정상 관측값과 원래 날짜를 보존하며 작업은 실패로 표시합니다. 다음 예약 실행에서 재시도합니다.
- 원천의 공표 주기와 사이트 수집 주기는 다릅니다. 금융위원회 자료는 원칙적으로 기준일 다음 영업일 오후 1시 이후 제공됩니다. 월별·분기별 통계를 일별 자료로 취급하지 않습니다.
- 같은 장중 가격에 갱신 시각만 붙이던 자동 실행은 중단했습니다. 실시간 가격으로 표시하려면 신뢰할 수 있는 측정 시각을 제공하는 별도 원천이 필요합니다.
- API 키는 GitHub **Settings → Secrets and variables → Actions**에만 저장합니다. 브라우저에는 공개 JSON만 전달합니다.

| Secret | 용도 |
|---|---|
| `ECOS_API_KEY` | 한국은행 ECOS 통계 수집 |
| `DATA_GO_KR_API_KEY` | 공공데이터포털 금융투자협회종합통계정보 |
| `KRX_ID`, `KRX_PW` | 사용자가 선택한 수동 로그인 진단만 사용 |

KRX 직접 수집 자료의 신규 공개 재배포는 API 이용 승인과 별도입니다. 현재 새 지수·외국인 수급은 출처가 명시된 ECOS 통계를 사용하고 기존 KRX 기록은 별도 시계열로 보존합니다. 로그인 진단은 비밀번호·아이디·쿠키를 출력하지 않습니다.

## ETF 변화

두 날짜의 **전체 목록**이 확인된 경우에만 편입·편출을 계산합니다. 신규=이전 목록에 없는 종목, 편출=현재 목록에 없는 종목, 확대·축소=공표 비중의 증감입니다. 변화폭은 현재 비중−이전 비중(%p)입니다.

가격 변동으로도 비중이 달라질 수 있어 확대·축소를 실제 매수·매도로 단정하지 않습니다. 수량은 ETF 전체 수량이 아닌 1설정단위(CU) 기준입니다. 서로 다른 날짜의 공시 관행을 맞춘 것처럼 바꾸지 않고 ETF별 기준일을 표시합니다. 검증된 일자별 자료와 수정 전 버전은 `data/etf-history/`에 보존합니다.

GitHub 실행 서버에서 TIGER·KoAct 운용사 원천은 HTTP 403을 반환했습니다. 해당 요청은 제한을 우회하지 않고 실패로 기록하며 마지막 직접 검증 자료를 유지합니다. TIME·DS는 GitHub 자동 수집을 확인했습니다. 네이버 대체 경로는 공개 재배포 제한을 확인해 최종 배포에서 제외했습니다. MIDAS는 허용된 구성종목 원천 또는 별도 재배포 권한이 필요합니다. 따라서 ETF 5개 모두의 매일 갱신이 완료된 상태는 아닙니다.

## 정량 모델

이 점수는 **초기 고정 가중치의 실험적 연구 지표**입니다. 투자 성공 확률로 해석하지 않습니다. 가중치는 화면에서 변경할 수 있으며 기준 설정은 `lib/analytics.mjs`의 `DEFAULT_CONFIG`입니다.

| 점수 | 초기 가중치 |
|---|---|
| 과열 | RSI 30, 60일 이격 20, 신용잔고 20일 증가율 25, 신용/예탁금 25 |
| 스트레스 | 20일 실현변동성 25, 환율 20일 변화 20, 신용스프레드 20, 반대매매 5일 평균 20, 신용/예탁금 15 |
| 모멘텀 | 200일 이격 30, 20일 수익률 25, 외국인 20일 수급 20, 기관 20일 수급 15, 60일선 상회 비율 10 |

지표의 이전 252개 관측값에 대한 중간순위 백분위를 구한 뒤 유효 가중치로 가중평균합니다. 최소 가중치 충족률 60%와 서로 다른 경제 요인 2개가 필요합니다. 과거 1·3·5년 창은 252·756·1,260개 전체 관측값이 있어야 계산합니다. 표준편차는 표본 표준편차입니다. 상관 경고는 중복을 알려줄 뿐 자동으로 가중치를 최적화하지 않습니다.

국면은 사전 정의한 일곱 조건으로 분류합니다. 상승 국면에는 실제 20일 수익률 양수 조건도 필요합니다. 조건을 만족하지 않으면 판단 보류로 표시합니다. 기여 지표의 실제 관측일을 함께 표시하므로 지수 최신일과 다를 수 있습니다.

## 백테스트와 한계

- 공표 시차를 적용한 결정 후 **다음 관측 종가**에 진입하고 5·20·60·120거래일 보유합니다. 배당·비용은 제외합니다.
- 같은 조건의 수익 구간은 중복되지 않게 선택합니다. 비교군은 해당 조건을 계산할 수 있는 날짜로 제한합니다.
- 5건부터 기술통계, 30건부터 평균의 Bartlett HAC 95% 구간과 상승 빈도의 Wilson 구간을 표시합니다. 최대낙폭은 보유 구간의 종가 경로를 사용합니다.
- 63거래일 워크포워드 검증에서는 그 전에 결과가 알려진 학습 표본만 이용합니다. Brier 점수는 같은 평가 사례의 무조건 상승 빈도 기준과 비교합니다.
- 과거 발표 시각과 수정 이전 빈티지가 모두 확보된 것은 아닙니다. 공표 지연 가정, 잔여 의존성, 다중비교, 원천 변경에 따른 재계산 한계가 있습니다. 결과는 과거 빈도이며 보정된 미래 매매 확률이 아닙니다.
- 종목별 과거 상장 목록·수정주가, 기업 컨센서스, 허용된 파생 시세가 없는 항목은 N/A입니다. 시장 확산도·선행 PER·EPS 수정·행사가별 포지션·롤오버를 가짜 값으로 생성하지 않습니다.

## 2026-11-27 검증 기록

시장 데이터 연결 테스트에서 76개 등록 항목 중 43개에 실제 관측값 95,713개가 확인됐습니다. 이 수에는 같은 원천의 파생 계산 시리즈도 포함됩니다. ECOS 코스피·코스닥 2,673개 종가(2016년 이후), 11월 26일 지수·외국인 수급·환율·한국 금리, 11월 25일 예탁금·신용·CMA·MMF를 확인했습니다. 월별 PER·배당·주가지수선물 및 옵션 거래량은 130개 기준월을 확보했습니다.

| 고정 조건 백테스트 | 비중첩 표본 | 평균 수익률 | 검증 결과 |

| 스트레스 ≥75, 이후 5거래일 | 88 | +0.277% | 표본 외 57건, Brier 0.24253 / 기준 0.24318 |

첫 결과의 개선은 작고 마지막 결과는 기준보다 나쁩니다. 우월한 예측 성능이나 검증된 매매 확률을 주장하지 않습니다. 네 보유기간의 표본 수·평균·낙폭·표본 외 점수는 독립 계산으로 대조했습니다. 실제 수치와 조건별 전체 결과는 `data/research.json` 및 백테스트 탭에서 확인합니다.

화면 검증에는 모든 탭·기간 버튼, 날짜 선택, 커서 동기화, 드래그 확대, 범례, CSV, 기술지표, 가중치 변경, 다크 모드, 390px 화면, 기존 전체 차트가 포함됐습니다. 수집 실패 재현에서는 이전 정상값을 보존한 뒤 실패 코드로 종료하는 것을 확인했습니다.

## 검증·로컬 실행

```sh
pip install -r scripts/requirements.txt
python -m unittest discover -s scripts -p 'test_*.py'
python -m unittest discover -s tests -p 'test_*.py'
node --test tests/analytics.test.mjs
python scripts/verify_data.py
node scripts/analyze.mjs
python -m http.server 8000 --bind 127.0.0.1
```

Pages 배포에는 `scripts/package_pages.py`가 허용한 HTML/CSS/JS/공개 JSON만 포함합니다. 환경 파일, 원응답 작업 폴더, 테스트 출력은 배포하지 않습니다. 시장·ETF 원응답은 수집 작업의 `outputs/raw/`에 분리되며 GitHub 실행 종료 후 장기 보관되지는 않습니다. 장기 원응답 감사 저장소는 별도 연결이 필요합니다.
